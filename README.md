# AWS Auditor Pro

AWS Auditor Pro is a Python-based AWS auditing tool designed to identify potential cloud cost optimization opportunities.

## Features

- EC2 analysis
- Running/stopped instance detection
- EBS volume analysis
- Unattached volume detection
- S3 bucket reporting
- Findings & recommendations
- Estimated savings report

## Technologies Used

- Python
- boto3
- AWS EC2
- AWS S3

## Purpose

This project was built to learn AWS cloud auditing and understand AWS optimization workflows.

## Example Findings

- Stopped EC2 instances
- Unused storage volumes
- Potential monthly savings
